# Live appearance propagation

Coordinated contract and acceptance: [umbrella design](../../../../docs/initiatives/live-appearance/DESIGN.md).

Version themed icon URLs in Places, Devices, list/grid views, information panel and Quick Look with HnAppearance.revision. URL changes invalidate Qt Quick images without directory reloads, selection changes or window recreation. Consume the staged File Browser provider and verify cache/DPR regressions and manual native appearance switches.
