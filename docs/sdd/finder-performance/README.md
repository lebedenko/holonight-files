# Finder performance

Status: Superseded by [shared search adoption](../shared-search-adoption/README.md).

The UI prototype's 2,500-file fixture measured 20–42 ms for a cold scan and 10–11 ms for a cached query. The user reported poor speed on their real tree, so that small fixture was not acceptance evidence. The shared initiative now measures a two-million-path session index, cold progress, first result, memory, and warm query latency in Files. This separate Files-only cycle has no active tasks.
